✈️ TravelPlan AI

> An intelligent, all-in-one travel planner powered by Machine Learning and Google Gemini AI — helping you plan trips, discover destinations, manage budgets, and navigate transport in real time.

🌟 Key Features
🗺️ Smart Destination Discovery
• ML engine (Random Forest + cosine similarity) trained on 100+ destinations  
• Personalized picks by budget, duration, and travel style  
• Filters by continent, climate, and preference

📅 Gemini-Powered Itinerary Builder
• Generates detailed day-by-day plans with real venues and neighborhoods  
• Includes restaurant and dish suggestions, local tips, transport and entry info  
• Auto-switches to dataset planning if Gemini is unavailable  
• ✨ Gemini AI Verified badge for AI itineraries

🚉 Real-Time Transit Map
• Live data from OpenStreetMap Overpass API  
• Accurate transit types: 🔴 Metro · 🟢 Rail · 🔵 Bus · 🟣 Tram  
• Clickable station chips with pan-to-location feature  
• Optimized for large metro systems like Mumbai Rail

💰 Budget & Wallet Manager
• Multi-currency wallet with live rates  
• Auto-generated wallet QR code  
• Tracks expenses and trip budgets

🌤️ Weather & Packing Advisor
• Live weather + forecast for each stop  
• Tailored packing tips per climate

🍽️ Food & Culture Explorer
• Local dishes, dining spots, and etiquette guides  
• Regional highlights for authentic experiences

🌐 Built-in Translator
• Quick phrase translation for major travel languages  
• Essential survival phrases included

🤖 Gemini Travel Chat
• Floating AI assistant for planning, tips, and local help on the go
